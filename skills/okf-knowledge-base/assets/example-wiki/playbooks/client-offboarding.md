**Draft.** Written after the last two projects ended differently from each other. It has not
been run start to finish yet, and the licence step in particular is unsettled.

# Trigger

The last deliverable is accepted, or the client ends the project early.

# Steps

1. Assemble the handover: source files, exported assets, and a written summary of what was
   built and what was left undone.
2. Check the licences for every font and stock image against what the
   [kickoff](client-kickoff.md) summary promised. *Open question: who pays when a licence the
   client wants costs more than was quoted.*
3. Send the final invoice per [invoice a client](invoice-a-client.md), including any
   pass-through costs still outstanding.
4. Remove client credentials from studio machines and shared vaults within five working days.
5. Ask the client what was worst about working with us, and write the answer down somewhere
   the next project lead will see it.
